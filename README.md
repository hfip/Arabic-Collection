# مجموعة كابتن الضخمة — النسخة العربية

نسخة مُعرَّبة من مشروع [Kaptain Collection](https://github.com/ImKaptain/Kaptain-Collection) الأصلي.

## ما هذا؟

أداة ويب تتيح لك تخصيص مجموعة Nuvio الخاصة بك: اختر المجلدات، اضبط المصادر، وأرسلها مباشرةً لحساب Nuvio أو حمّلها كملف.

## المميزات

- واجهة كاملة باللغة العربية مع دعم RTL
- خط Cairo لعرض العربية بشكل مثالي
- جميع النصوص والرسائل والتوجيهات بالعربية
- أكثر من 350 مجلداً مخصصاً في 11 فئة

## الفئات

- 🔥 الرائج والجديد
- 🎬 خدمات البث
- 📺 القنوات التلفزيونية
- 🎭 الأنواع
- 📦 مجموعات الأفلام
- 🌟 الممثلون
- 🎥 المخرجون الأساطير
- 🏰 الاستوديوهات
- 📅 حسب العقد
- 🔥 الأنمي
- 🏆 الجوائز
